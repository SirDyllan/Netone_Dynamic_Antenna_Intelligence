DASHBOARD TINKERCAD TOWER CIRCUIT ↗
ACADEMIC PROTOTYPE

No physical components are required. The dashboard runs the autonomous decision loop; Tinkercad Circuits provides a separate virtual Uno-and-servo model. Synthetic demand and scores are not live NetOne measurements or a validated propagation model.

The decision engine forecasts a next demand window from simulated history, searches bounded antenna settings, and holds position when guardrails do not support an adjustment.

01 / QUICK START

Run the application

  1. Install Python 3.10 or newer.
  2. From the project root, run py -m pip install -r requirements.txt.
  3. Run start_demo.bat or the PowerShell launcher start_demo.ps1.
  4. Open http://127.0.0.1:8000. The API runs at http://127.0.0.1:5001.

The backend entry point is py backend/server.py. The optimizer implementation is ai/optimizer.py; it is not a server entry point.

Each current scan contains 72 directional sectors at five-degree intervals and three synthetic prior windows. A damped per-sector trend estimates the next window. The engine searches azimuths from 0°–180° in five-degree steps and demo tilts of 3°, 6°, 9°, and 12°. It maximizes forecast demand-weighted coverage, limits each azimuth move to 45°, and prefers less movement on ties. It automatically holds if the simulated consistency indicator is below 65% or forecast gain is under 2 points. The consistency value is not a calibrated probability, and the score is not RF performance.

03 / LANGUAGE ASSISTANT

Configure an OpenAI-compatible model

The assistant explains scans and actions in the dashboard. With no model configured, it uses a clearly labeled local response mode. To enable generated responses, set these environment variables before starting the backend:

$env:NETONE_LLM_MODEL = "your-model-name"
$env:NETONE_LLM_API_KEY = "set-this-in-your-own-terminal"
py backend/server.py

Credentials are read by the backend and are not sent from the browser. The assistant endpoint is POST /api/assistant. Unset the variables to use the local assistant. Do not place a real key in this page, source control, or browser storage.

The dashboard can also speak assistant replies using the browser's speech synthesis when “Speak assistant updates aloud” is enabled.

04 / TINKERCAD DIGITAL TWIN

Virtual circuit setup with no purchases

Open the GreenHex virtual circuit in Tinkercad ↗. Add virtual components from Tinkercad's library; do not buy an Arduino, servo, breadboard, or wires.

  1. Add an Arduino Uno R3 and one Micro Servo.
  2. Connect the servo signal to D10, VCC to 5V, and GND to Arduino GND.
  3. Open Code, choose Text, and load hardware/arduino/antenna_controller.ino.
  4. Start Simulation. The virtual servo begins at 35°. Use the sketch's DEMO sequence to show several allowed angles.
  5. Run the dashboard autonomous cycle. If the simulator accepts serial input, enter the displayed SET AZIMUTH N command to mirror the recommendation. Otherwise, narrate the target and run the virtual sweep as the actuator illustration.

The web dashboard and hosted Tinkercad simulation are separate tools; this prototype does not remotely command the Tinkercad circuit. The dashboard demonstrates forecast, decision, guardrail, and score verification. Tinkercad demonstrates how the virtual actuator responds to valid azimuth commands.

This is an academic simulation. Do not present synthetic scores as measured RF results or as a live connection to a NetOne site.
